# 流量估计、指标与复盘

## 把“点击量预测”拆成可测的问题

先确认用户指播放量、内容点击数还是 CTR，指定平台、账号、作品类型和窗口（例如发布后 24h/7d）。没有相应观测值不能换个指标冒充。短视频自动播放尤其不能把播放叫封面点击。

| 数据条件 | 可交付 | 不应交付 |
|---|---|---|
| 只有报告/竞品可见点赞 | 需求证据、选题评分、增长假设和采样方案 | 从点赞反推播放、CTR、成交或爆款概率 |
| 本账号有少量同窗作品 | 描述历史样本和缺口，给相对候选排序 | 稳健的数字预测或标题加成倍数 |
| 本账号至少 10 条同条件定窗播放 | 同类作品经验 q10/q50/q90、样本与限制 | 声称 80%保证落在区间，或代表新题材的专属模型 |
| 有足够历史和回测 | 时间顺序验证后的基线、误差、覆盖与漂移分析 | 随机拆分后夸效果、把未验证学习模型用于自动发布 |

10 条是工具的最低描述门槛，不是统计充分的证明。季节、算法、粉丝结构和内容质量仍会变化。内置工具只估**自然播放次数基线**，不估 CTR/真实点击/成交，也不会依据标题或创意评分调整流量。

## 预测工具输入

标准库脚本 [forecast.py](../scripts/forecast.py)，无需联网。历史 UTF-8 JSONL 每行一作品的一个固定窗指标：

```json
{"post_id":"p01","platform":"douyin","account_id":"a01","pillar":"balcony","format":"video","duration_bucket":"30-60s","traffic_type":"organic","metric_kind":"fixed_window","window_hours":24,"published_at":"2026-09-01T10:00:00+08:00","captured_at":"2026-09-02T10:05:00+08:00","views":800}
```

`fixed_window` 表示指标明确为发布后前 24h 累计，**不是任意时刻的终身累计快照**。后台只给当前累计，则记录原始快照和实际经过小时，不能改名塞进 fixed_window。定时抓取也会有延迟，应先制定允许偏差并披露，内置基线只接收口径已确认的定窗数据。

目标 JSON：

```json
{"platform":"douyin","account_id":"a01","pillar":"balcony","format":"video","duration_bucket":"30-60s","window_hours":24,"as_of":"2026-10-30T12:00:00+08:00","lookback_days":60,"max_samples":100,"min_samples":10}
```

时间必须带时区，`as_of` 是预测时已知信息截止点。严格匹配账号、平台、支柱、形式、时长桶、自然流量与窗口；过滤未来、未到窗、缺播放和错误时间数据，去重同一 post_id，取截止点前最新有效修订。不同分层不能为了凑数静默混入；如要扩大支柱或时长桶，先单独出诊断并明确改了假设。

调用：

```powershell
python -X utf8 "<skill目录>/scripts/forecast.py" --history "<运行目录>/metrics.jsonl" --target "<运行目录>/forecast-target.json" --output "<内容目录>/forecast.json"
```

q10/q90 是历史可比作品的经验范围，q50 为中位数，**不是已校准的未来置信区间**。输出包含排除原因、样本ID、基线方法、回测和限制。零播放保留；缺失不填零；有效爆款保留，不仅因高就删。

回测按时间滚动：每条过去作品仅用当时已经取得指标的更早作品预测，至少 min_samples 条训练；报告样本量、MAE、log1p-MAE 和 q10–q90 经验范围覆盖率。少于 10 个可回测作品只作描述、不称校准完成。发布选择偏差、延迟可见与账号漂移仍会影响回测。正式加入特征模型前必须胜过这个时间外基线，并记录样本、模型版本、误差和失效条件；本 Skill 不自带“爆款 AI 模型”。

## 数据回收

按实际发布而非排期时间起算，建议检查上线状态后收集 24h、72h、7d（可调）的数据；每条记目标截止点、实际抓取时间与来源。指标不存在、无权限、没到窗、未加载分别记录，不混为零。

除播放外，尽可能取平台明确提供的曝光、点击、观看时长、留存/完播、赞评藏转、关注、负反馈；商业内容另记有效咨询、订单、退款和成本。去重咨询对象及订单，评论“多少钱”不算成交；没有购买归因数据就不给内容成交贡献。

计算派生指标时附公式，例如 `收藏率=同窗收藏/同窗播放`；分母零记 null。总互动可能一人多次，不称独立用户比例。指标定义来自当前平台映射，不能用页面顺序猜字段。

## 诊断与实验

低曝光且打开未知→先查账号状态、审核、上传完整性、分发口径；不能断言封面差。曝光正常且可比 CTR 低→试一个标题/封面变量；打开正常但早期流失→查承诺、开场、画面和适用对象；收藏好关注弱→查系列价值与身份一致性；流量高但咨询/成交弱→查受众、商品适配、履约及归因，不直接归因算法。

每轮只改变一个主要变量，保留候选版本、预注册假设、主指标、窗口、样本要求和停止条件。优先平台原生实验；不支持则做有条件的同类作品序列比较，说明非随机、季节和题材混杂，不称因果 A/B 结果。不要重复上传同一视频刷测试。

周复盘写：本轮事实和缺失→同窗可比基线→预测误差→成功/失败解释及替代解释→保留/停止/测试的具体动作。一个爆款不推翻全策略，低表现也不等于违规或被限流；先核查证据。更改配置有版本和依据，不能悄悄把假设升级成规律。
